# Photo Split

Утилита для автоматической раскладки и переименования фотографий документов по заданным комбинациям параметров (угол съёмки, освещение, фон).

## Назначение

Программа сортирует набор фотографий по **48 уникальным комбинациям**:
- **Угол**: 0°, 20°, 45° (3 варианта)
- **Освещение**: Natural-daylight, Office-LED, Warm-indoor, Dim-light (4 варианта)
- **Фон**: Neutral wall, Textured desk, Outdoor pavement, Docs-on-docs (4 варианта)

Файлы распределяются циклически:  
угол меняется каждые 2 фото → освещение каждые 6 → фон каждые 24.

## Структура входных данных

```
📁 Ваша_папка (указывается при запуске)
 ├── 📁 Россия
 │    ├── 📁 1234567890  (Passport ID)
 │    │    ├── photo1.jpg
 │    │    ├── photo2.jpg
 │    │    └── ...
 │    └── 📁 9876543210
 │         └── ...
 └── 📁 США
      └── ...
```

## Формат выходных файлов

```
{PassportID}_L{1-4}_B{1-4}_A{1-3}_D{1-2}.{ext}
```

Где:
- `L1–L4` — номер освещения
- `B1–B4` — номер фона
- `A1–A3` — номер угла
- `D1–D2` — номер документа (чередуется)

## Использование

Скачайте последний релиз или соберите сами:

```bash
pyinstaller --onefile --name photo-split main.py
```

Готовый файл появится в папке `dist/`.

## Зависимости

- Python 3.x
- Стандартная библиотека (`os`, `shutil`, `msvcrt`)
